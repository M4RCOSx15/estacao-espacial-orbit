# Missao: Monitoramento de Suporte de Vida

## Descricao do Projeto
Sistema desenvolvido em Java para a verificacao automatizada de parametros criticos de suporte de vida, incluindo niveis de oxigenio, pressao do modulo e o estado operacional do sistema de reciclagem de agua.

## Camadas do Ambiente
* **develop**: Ambiente dedicado ao desenvolvimento continuo, implementacao de novas rotinas de diagnostico e integracao de codigo.
* **stage**: Ambiente de homologacao e testes de integridade, simulando os cenarios de operacao espacial antes da liberacao para producao.
* **main**: Ambiente de producao oficial, responsavel por executar as rotinas criticas de monitoramento em tempo real.
